RetailIQ Dataset

This folder is intended to contain the datasets used by the RetailIQ — AI-Powered Retail Intelligence Platform.

Due to GitHub file-size limitations, the complete dataset is not included in this repository.

📊 Dataset Usage

The dataset is used for the following components of RetailIQ:

📈 Sales Forecasting — historical sales data used to train forecasting models.
🛒 Product Recommendation — product and customer-related data used by the recommendation system.
🖼️ Product Image Classification — retail product images used to train the computer vision model.
🤖 RAG Assistant — project-related information used by the Retrieval-Augmented Generation system.
